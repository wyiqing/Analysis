# Microbiome and Microbial Neprilysin Homolog Analysis

## Overview

This repository contains raw and processed 16S rRNA sequencing data, sequence datasets for microbial neprilysin (mNEP) homolog analysis, phylogenetic and prevalence-related materials, source files for representative NEP homologs, and expression vector information.

## Repository Contents

### 1. 16S Data
- Raw 16S rRNA sequencing data
- Processed data and analysis results

### 2. Phylogenetic and Prevalence Analysis
- Scripts
- Sequence datasets and processed data
- Analysis workflows
- Phylogenetic tree files

### 3. source data
- Expression vectors and sequence files for expression
- Representative NEP homologs and predicted structure

### 4. Comparative Sequence Analysis
- Sequence comparison data and analysis results

### 5. ProGenomes-Based Prevalence Analysis
- BLASTP analysis scripts and workflow
- Local protein database
- Scripts and workflows for prevalence analysis
- Prevalence statistics and related results

## Data availability

Scripts, analysis workflows, and newly generated data are available in this GitHub repository. Reference datasets are archived on Zenodo.
