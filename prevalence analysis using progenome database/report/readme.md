### Step 3. Prevalence Analysis Using Greengenes2

The prevalence of *Lactobacillus* and *Ligilactobacillus* in the gut microbiota was assessed using the Greengenes2 database ([https://greengenes2.ucsd.edu/]).

- *Lactobacillus* (lac): 842/864 (97.45%)
- *Ligilactobacillus* (lig): 270/276 (97.83%)

Prevalence was calculated as the proportion of samples in which the respective genus was detected among all samples analyzed.
