# ProPan Dataset for M13 Family Enzyme Analysis

## Overview
This dataset contains fully sequenced strains representing 23 *Lactobacillus* and *Ligilactobacillus* species obtained from the ProPan database. These data were used to investigate the distribution of M13 family enzyme homologs across individual species and classify them as core or dispensable genes.

## Reference
Zhang Y, et al. ProPan: a comprehensive database for profiling prokaryotic pan-genome dynamics. *Nucleic Acids Research*. 2023;51:D767–D776.
